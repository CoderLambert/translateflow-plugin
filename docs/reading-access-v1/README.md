Actual sender.id must equal runtime.id. HTTP(S) Content is main frame0, normal native sender.tab, active document if provided. Native106+ documentId binds scripting target/result; legacy102 uses controlled frame0/navigation generation, not caller IDs. Extension pages require114+ getContexts exact one context with native opaque documentId/documentUrl/contextType/incognito/optional tab match (contextId is UUID); only exact learning-center.html receives history authority. Options/Popup receive only fixed open. Missing native private proof is CAPABILITY_LIMITED; no background spanning incognito flag fallback. The actual Chromium153 diagnostic showed documentId as32 uppercase hex digits in sender/scripting/getContexts, with exact equality; UUID-form documentId is also accepted without string normalization. The original UUID-only assumption caused3 native positive failures (retained), then the format guard was repaired without weakening native ownership/private checks. Browser102 itself is NOT tested by modern Chromium.

Returned trusted authority includes scope/ownerKey/tabId/nativeDocumentId/documentGeneration/navigationGeneration/authorityGeneration and Content pageKey/siteKey/safeReturnUrl/native bounded pageTitle/selectionGeneration/proof. Caller URL/title/time/safety cannot replace these. ownerKey stays internal; token does not expose browser identity. Navigation loading/any native URL string update (including same-document hash/tracking/query reordering), removed tabs, permission revoke, changed owned document/selection and worker restart invalidate old operations. This intentionally conservative Reading capability boundary does not cancel #231 ordinary query/card state: #234 may prove the still-current frozen source and fresh register/begin/save without another Provider request. No old-token continuity across URL updates is promised. Native Popup context.tabId=-1 has no tab navigation entry; exact contextId/documentId/URL/incognito and post-await getContexts still apply, so it can only fixed-open and a closed context fails. Tracked sessions/navigation/subscriptions are bounded128 design entries; listeners ignore unrelated tabs for allocation. Revoke uses a monotonic transient authorityGeneration rather than resetting to1. Native extension context is rechecked after async repository work before returning a response.

Subscriptions reserve the shared128 pending-plus-active slots before native authorization starts. Disconnect, caller messages, refused authorization/repository replies and close release the reservation; close cannot be followed by a pending registration resurrecting it. Only active authorized entries receive publications. Tab navigation/removal revokes exports owned by that native tab, while unrelated tab events preserve other owners; permission/global policy revocation still interrupts all active exports. A buffered export retry rechecks repository policy/revision, then confirms its exact cursor and cached block have not advanced across the await. Concurrent advancement returns INTERRUPTED rather than another cursor's chunk; an unchanged cursor returns the original chunk.

An export start may become active only if its original reservation is still starting, current and within TTL after the repository await. Pause/revoke, cancellation and owner navigation cannot resurrect it. Failed starts release their unchanged starting reservation; an already acknowledged concurrent cancellation retains its bounded receipt. Finish remains governed by C3: the adapter checks owner/revision/EOF at its short transaction boundary, and a successful finish acknowledgement precedes UI Blob download. Pending finish rejects cancellation; interruption before finish delivery is not a saved-file acknowledgement and does not claim rollback of any committed repository transaction. A delivered finish receipt remains finished through revocation, and later cancellation cannot retract that copy. Actual persisted commit/receipt and disk outcomes remain #233/consumer acceptance, not Node-double evidence.

Starting, active, finishing and cancelling sessions all occupy the1-owner/2-global export limits; a pending terminal repository acknowledgement cannot admit another live export. Finished/cancelled acknowledgements release that live slot while their receipts remain within the original TTL/global receipt bound.

## #233 repository interface (single IDB owner)

Only future `src/background/reading-record/idb.js` directly opens Reading IndexedDB. Other Reading modules call this adapter; no cache DB/OPFS/chrome.storage second consent/metadata store. Unknown future DB version never deletes/resets data. Methods below are authoritative asynchronous adapter functions, not messages. Every context contains `{request,access,assertCurrent}`; access was derived by this service, not reconstructed from a DTO. assertCurrent is synchronous and must run at the final short transaction commit/read boundary. Adapter must recheck native-derived authorization, consent/site exclusion/private/document/deletion generations and stored page while reading/writing atomically; an earlier readPolicy result is insufficient.

| Adapter method | Transaction responsibility / result |
| --- | --- |
| readPolicy(context) | Content readonly meta/site policy: `{siteExcluded:boolean}`; no caller siteKey. Then each later read/write rechecks policy in its own transaction. |
| read(context) | Atomic authorized read for summary/detail/list/page aggregate/state/site/exclusions; exact v2 success data. Content stored record.pageKey must match authority; excluded site blocks automatic summary. GET_RECORD may update viewed metadata and exportRevision in a separate authorized short RW transaction, never lookupCount. |
| prepareOperation(context + `{previous:null|token,sourceSnapshot,issuedAt,expiresAt}`) | Read live meta/page/site/record and actual same-page existing record; no empty record creation. Return `{state:'disabled'}` or `{state:'ready',token}`. Backend clock fixes issuance/TTL. A same-id retry must preserve previous token exactly and recheck policy; stale/expired id requires a new explicit operation, never automatic Provider repeat. |
| mutate(context + `{registeredOperation,artifactDigest}` for artifact writes) | Short RW transaction checks registered owner/token/capture, current consent/site/page/data/record revision and expiry, then idempotent receipt/capacity/immutable rows. Same artifactId+canonical digest returns original receipt; changed payload rejects. Operation receipt counts first lookup artifact only; late Rich appends without another count; assistant append does not count. Management changes use validated expected generation/revision in the same transaction. Returns exact committed response data. |
| cancelOperation(context + `{registeredOperation}`) | Short RW transaction linearizes real cancellation versus prior artifact commit; returns actual cancelled/committed state. Persisted cancel tombstone prevents late transaction commit. Retry returns actual receipt, not fabricated rollback. Service revokes transient registration only after cancellation acknowledgement. |
| readInvalidationState({access,assertCurrent}) | Short policy-checked readonly current revisions. LC `{protocolVersion:2,type:'reading.invalidate',catalogRevision,dataGeneration,consentGeneration}`; Content substitutes pageRevision and receives no global catalog revision/text/URL/Q&A. |
| openExport(context) | Short readonly snapshot metadata `{exportRevision,exportedAt,position}`; stable record→snapshot→artifact row order, no getAll. |
| checkExport(context + `{exportId,exportRevision}`) | Short readonly revision/policy check even when retrying the buffered same cursor. |
| readExportChunk(context + `{exportId,exportRevision,exportedAt,position,sequence,maxChunkBytes}`) | Short readonly revision check and continuous canonical JSON fragment; returns `{exportRevision,position,jsonChunk,done}`. Bound raw UTF8≤256KiB and serialized response≤1MiB; never split surrogate. Records can span fragments. Position is internal opaque adapter state, not caller input. |
| finishExport(context + `{exportId,exportRevision,position,sequence}`) | Short authorized transaction checks fixed revision and exact EOF/sequence before successful finish delivery. No transaction spans messages/no write locking. Revision change interrupts; actual storage/worker interruption has no success ack. |
| cancelExport(context + `{exportId,exportRevision}`) | Actual owned cancellation cleanup/receipt boundary; after finished delivery reports finished and cannot retract user's copy. |

Management revisions: first/late artifact append increases record revision, relevant pageRevision/catalogRevision/exportRevision, never dataGeneration. Viewed changes increase exportRevision (and record revision only if its model changes), not automatically catalogRevision. Clear increments dataGeneration even empty; preserves consent/exclusions. Page delete increments pageGeneration even empty and removes page-owned rows/receipts; record delete invalidates target. Consent pause/resume changes consentGeneration, site exclusion/resume changes sitePolicyRevision; neither revives old tokens. Fixed op registration is transient (16/owner128global10min, no renewal); persisted receipt/tombstone pruning cannot revive expired token or lost worker registration. Site origin index remains available when safeReturnUrl=null. Publish invalidation only after commit; UI rereads on focus/reconnect/restart and never resurrects a deleted detail from a late response.
