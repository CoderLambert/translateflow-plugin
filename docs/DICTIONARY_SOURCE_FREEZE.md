# Dictionary source freeze

Decision date: 2026-09-30. This matrix freezes source direction, trust class, package role, and the repository's current license/provenance status. It records qualification decisions; it does not approve sources beyond the roles stated here.

For #116 source qualification, the exact Wiktionary Rich source/extractor/projection path is **NO-GO**, not a source approval and not a GO decision for another candidate. Its full Rich benchmark, zh-CN audit, pack size, and lookup-performance criteria were not measured. The required #122 GO and approved-source prerequisites therefore remain unsatisfied.

## Frozen product roles

- Keep PWN 3.0 + COW as the bounded bundled semantic bootstrap; do not treat its mapped coverage as complete EN→ZH coverage.
- Keep the existing ECDICT path labeled `curated-upstream`, direct-to-upstream, and user-triggered. Do not describe that trust class as approval to mirror or relicense ECDICT content.
- Treat OEWN as a semantic supplement candidate and CC-CEDICT as a native zh→en candidate. Neither is an authoritative primary EN→ZH source under the current evidence.
- Keep FreeDict eng-zho 2025.11.23 **NO-SHIP** despite its completed legal packaging gate.
- Keep the exact Wiktionary Rich path **NO-GO**. Its partial schema counts are incomplete observations; full extraction, complete pack metrics, and source-wide quality measures are not available.
- Keep validation terms, manual compatibility records, source snapshots, locks, and build evidence outside production dictionary payloads. See [lexical data boundaries](LEXICAL_DATA_BOUNDARIES.md) and [the lexicon workspace policy](../lexicon/README.md).

## Evidence precedence

This matrix uses the source locks, quality decisions, and issue/PR evidence linked above. Older candidate-role notes in [Selection v2 Design Freeze](SELECTION_V2_DESIGN_FREEZE.md) are historical where a later source-specific quality decision now exists; in particular, the current FreeDict decision is NO-SHIP. An exact lock establishes which bytes and revisions were measured. It does not by itself establish product quality, rights to redistribute, or production eligibility.
