# AI 文本翻译

在 Popup 顶部或网页悬浮球面板点击「AI 文本翻译」，打开独立小窗。再次点击会聚焦已打开的窗口。普通浏览器窗口中的受保护页面也可使用 Popup 入口；无痕模式暂不支持。可在 `chrome://extensions/shortcuts` 为「AI 文本翻译」自行设置快捷键。

粘贴或输入原文，选择目标语言后点击「翻译」，或按 Ctrl/Cmd+Enter。Enter 换行，输入法选词不触发发送。每次新内容独立翻译。场景胶囊提供「通用、邮件、办公、日常交流、学术、技术文档、社交媒体」，默认通用；点击选择实际影响下一次明确发送的翻译，不自动请求 AI，也不覆盖手写的「补充要求」。选择在本次浏览器会话内保留；继续调整旧译文沿用它的场景，旧记录默认通用。点击结果下的「继续调整」，仅围绕对应原文和译文生成新版本；「翻译新内容」或 Escape 返回普通输入并保留草稿。复制仅复制译文正文。

语言和 AI 服务使用紧凑下拉菜单：方向键选择，Enter 确认，Escape 关闭，Tab 离开；长服务名可悬停查看，重复服务/模型名称合并显示。

使用现有全局 AI 服务，或在小窗选择已配置的连接。选择仅影响小窗下一次请求，不改全局或站点设置。输入翻译使用独立翻译提示和严格结果校验，不带当前网页内容、站点覆盖或无关对话。服务读取、输入、切换设置不调用 Provider；明确发送才请求。当前实现完整输出通过校验后显示，不展示半成品。

同时只处理一个请求，可继续准备下一段。支持停止、失败原地重试；重新翻译是新的 AI 调用。关闭窗口会取消当前任务，重新打开将未结束项显示为中断，不自动续发。原文最多 6000 字符，补充要求最多 600 字符，超限不截断发送。

草稿和最近 20 条结果只存于受信的 `chrome.storage.session`，不进入持久翻译缓存、Reading 或学习中心。浏览器会话结束后清除；「新建对话」经确认清空当前草稿和结果。切换服务/语言不会自动重译既有内容。权限、配置或网络失败时保留原文供恢复。

图标使用用户提供的 icon pack v2：安装包仅包含 16/32/48/64/128px PNG，源文件位于 `assets/icons/`；64px 图标用于界面与标签页。网页 UI 仅额外暴露这一个固定图标路径，不暴露其他目录。
