# Offline Dictionary Library Beta certification

This gate certifies the current user-facing Beta through the existing test and release evidence. The aggregate report is written only after `npm run validate`, real-release-pack Chromium E2E, integrated lexical certification, and production-footprint certification have completed successfully in `.github/workflows/lexicon-release.yml`.

The aggregate reads Playwright's JSON reporter output, `integrated-lexical-certification.json`, and `extension-footprint-report.json`. It requires the named product tests to have an expected passing outcome with no skipped, failed, or retried attempt. It also requires every case reported by the ECDICT, StarDict, and MDict product spec files to pass. The complete Node test suite is a required preceding workflow step; its focused evidence files are listed in the generated report.
