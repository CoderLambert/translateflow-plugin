# TranslateFlow 支持 / Support

## 先恢复使用

1. 扩展更新后重新加载扩展并刷新网页。Chrome 内部页和商店页不支持页面注入，可从 Popup 打开 AI 文本翻译。
2. 核对当前翻译方式：AI 需要可用服务；免费在线需要联网同意且可能限流；Chrome 本地需要浏览器和语言资源支持；本地词典需要导入并启用。全文的免费在线选择不代表字幕和 AI 文本翻译也改用免费在线。
3. 按具体报错恢复，保留可用结果，避免反复发起可能计费的请求。不要先卸载扩展或清空全部数据。

设置 → 使用文档按功能提供操作步骤和问题排查。当前面向 Chrome；Chrome 本地模型能力取决于浏览器、硬件和语言，受保护页面、所有网站和任意第三方词典均不保证兼容。

## 提交问题

[打开 GitHub Issues / Open GitHub Issues](https://github.com/CoderLambert/translateflow-plugin/issues)

这是外部公开网站，需要联网，提交通常需要 GitHub 账号。点击链接本身不会附带你的配置、密钥、页面内容或诊断报告。

请提供版本（设置 → 关于）、操作系统和 Chrome 版本、功能入口、翻译方式、复现步骤、预期/实际结果、脱敏错误信息。可以提供公开网页链接；不要提交私人网址、API Key、聊天、完整服务请求或私有词典。截图先遮住个人信息。发现安全问题时先提出不含利用细节和秘密的联系请求。

维护者不会要求你将 API Key 发到 Issue。不承诺第三方服务响应时效、免费额度或所有模型的翻译质量。

## Recover first

After updating, reload the extension and refresh the page. Browser-internal and store pages cannot run page translation; the AI text window is accessible from the popup. Check the selected method and its requirements: configured AI, consent for free-online services, ready Chrome local models, or an enabled imported dictionary. Captions and AI text translation do not inherit the free-online page method.

Use Settings → User guide for feature-specific instructions. Keep usable results and follow the actual error; avoid repeatedly sending billable requests or uninstalling/clearing all data as a first step. Chrome local models depend on browser/hardware/languages; compatibility with every website or dictionary is not guaranteed.

## Report a problem safely

Use the GitHub Issues link above. It opens a public external service; posting normally requires a GitHub account. No configuration, credentials, page contents or diagnostic report is automatically attached.

Include extension/Chrome/OS versions, feature, translation method, reproduction steps, expected and actual behavior, and redacted errors. Public sample URLs are useful. Do not post secrets, private URLs, conversations, full service requests or private dictionary files. Redact screenshots. Initially request contact for security concerns without publishing exploit details or secrets.

The maintainer will not ask you to post API keys. Third-party uptime, free quotas and translation quality across all models cannot be guaranteed.
