# 划词上下文与滚动弹窗修复

## 目标与范围

基于 `9230667607117f41f33d823d5fd4209d64d011cf` 修复两个独立的划词交互问题：

1. 在由非语义化 `div/span` 组成的普通可见文本中，AI 解读仍应获得选区附近的局部上下文。
2. 页面滚动或弹窗内部滚动不应因无关 DOM 变更而关闭详情弹窗。

范围仅包括 Selection 内容脚本的局部上下文捕获、冻结选区有效性判断、弹窗生命周期，以及对应单元测试和本地 Chromium E2E。不修改 Native Host、Provider 凭据、用户词典、学习数据、权限、CSP 或浏览器 profile。

## 安全与行为边界

- 上下文仍限制在最近的安全可见块级祖先内，最多 900 字符；不发送整页文本。
- contenteditable、表单、Shadow DOM、自定义元素及其它现有敏感/不支持区域继续降级为 selection-only。
- 页面文本只作为不可信引用数据传入既有结构化请求；不得成为指令或扩大 Provider 请求权限。
- 选区 Range 断开、所选文本变化、路由离开、外部点击或 Esc 仍关闭弹窗；无关页面变更只重定位。
- 异步结果继续绑定冻结选区、页面身份和请求版本，旧响应不得覆盖新选区。

## 验收

- 单元测试覆盖非语义化块级上下文捕获、敏感区域不泄露、无关投影变更保留弹窗及真实选区变更关闭。
- 本地 Chromium E2E 使用公开合成页面和假 Provider，断言请求包含局部句子但不包含无关页面文本。
- E2E 区分页面滚动与弹窗内部滚动，并验证二者均保持弹窗；Esc 与外部点击仍关闭。
- 保存不含私密窗口的 E2E 截图，不进行真实模型请求。
