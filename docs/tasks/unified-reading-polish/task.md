# 统一阅读体验优化

## 目标与授权

用户要求统一优化并及时提交代码。本轮整合已有 Popup 和 YouTube 字幕改版，修复已重新授权处理的译文协议残片污染，检查失败恢复路径，交付统一版本安装包。允许本地提交；不默认推送、合入或发布商店。

## 范围

- 精确整合 `translateflow-popup-polish` 与 `translateflow-youtube-experience` 已有未提交成果，保留原工作区与旧包。
- 修复模型新引入的协议碎片进入译文，以及历史污染缓存被恢复的问题；保留原文中的合法代码/JSON/引号示例，使用既有有界重试与恢复，不直接删除字符伪装成功。
- 检查 Popup 的进度、失败后重试与真实取消；只对已确认缺陷做必要改动。
- 保留字幕当前句优先、倍率窗口、串行占用与过期隔离，以及用户明确授权的 pipeline.js 900行上限。

## 兼容与边界

继续使用现有 Provider、缓存服务、有效配置和任务协议。缓存内容校验只淘汰可确认的无效记录；不清空数据库、用户词典、设置或历史。若改动校验策略，补缓存读写与原文示例回归。没有新增 Provider、权限、后台服务或诊断平台。

## 验收与提交

先提交经过针对性验证的 Popup/字幕整合版本，随后提交译文质量与确认的恢复修复。每次提交同步版本并构建准确暂存区安装包。最终对统一代码执行适用的 Provider/缓存/页面/Popup/字幕回归、严格类型检查和真实 Chromium/MV3 验收，并由主 Agent 自查。历史验证不冒充本次集成验证；真实 YouTube 登录阻塞与合成播放器证据分开记录。
