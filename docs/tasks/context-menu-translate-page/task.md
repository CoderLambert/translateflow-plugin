用户希望右键网页就能翻译当前页面。入口应复用既有 translate-page 后台路由、已保存翻译方式、站点授权与Content任务机制，不建立第二套翻译流程。

范围：background contextMenus 注册/点击路由、必要的 `contextMenus` 权限、Manifest/隐私说明、设置快捷键提示、使用文档和README、单元/实际包冒烟。只对普通HTTP/HTTPS文档显示；点击使用Chrome报告的标签页而非另一个焦点窗口；非本扩展ID、无标签页、受保护页面忽略或拒绝。菜单标题使用本地化Manifest文案，失效上下文回退英文。右键不自动授予站点权限，仍走既有站点访问确认；不读取选中文字，不新增Provider或存储。
