# 字幕性能与资源生命周期修复

修复当前性能审查确认的三个问题：资源 Observer 重复安装、无关 DOM 引发字幕刷新、关闭后仍采集和全量重算。用户要求避免页面残留资源泄漏。

范围：MAIN bridge 的 Observer/监听/异步回调清理和轨道变化通知；字幕源关闭/重启、迟到安装、cue 时间索引及不再使用的 TextTrack 监听。保持现有 Provider、缓存、MAIN 安全边界、字幕同步语义和播放器底部入口。保留本地既有未提交功能。

验收：重复模式切换和启停资源数不增长，停止后释放自有资源；外部 DOM 更新零字幕快照；off 无采集/边界计时器，重新开启可用；迟到安装和异步回调不复活已停止实例；保留重叠字幕、空档、seek、倍速、轨道和播放器重建。运行定向 Node 回归、静态/类型、构建和相关 MV3 场景，并用隔离 Chromium 对比原性能探针。真实 YouTube 与合成验收分别报告。成功后更新用户原安装目录，不自动提交或推送。
