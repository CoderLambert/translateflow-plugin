# 主 Agent 自查

候选：`c61c8587e52ef56a76de1113b418bc59896732ee`（0.8.49）。这是主 Agent 对实际 diff、调用路径和真实页面截图的自查，不是独立模型审核。

## 已修复的确定性问题

1. **批次丢失源合同**：local batch 原先只保留 id/text，丢失 format/protectedIds；现保留源信息并提示模型保留代码内容。
2. **校验位于重试之外**：把完整 ID、非空值、标记与代码校验纳入 adapter 格式重试；不放宽协调器或缓存合同。富文本安全恢复复用 translationParts，只翻译普通文字槽并按原结构重组。
3. **标题协议污染**：首个候选虽然完成 13/13，但截图中标题包含其它段落和 JSON 残片，不能交付。最终候选拒绝值中原文没有的 JSON 围栏、协议字段、标记或跨段落协议残片；多段纯文本格式尝试耗尽后可拆成单段，单段不会继续拆分。保留原文已有协议示例；不会直接清洗或截断不可信输出来冒充成功。
4. **响应体取消/超时失去所有权**：HTTP linked signal 覆盖完整 body，SSE 在输出之前重试暂时故障，已经输出的流不重放，reader 正常释放。
5. **活跃快照过期**：Provider 执行期间保留冻结配置，使用/释放更新空闲期限，淘汰跳过活跃项；配置撤销、owner 校验和缓存写入身份保留，不复活失效对象。
6. **Native 并发争抢**：三类推理入口共用 FIFO；排队有数量/时间上限，排队取消不启动推理，断线不重放，运行中取消仍等 Host 终态。
7. **通用错误与反复自动重试**：固定错误码映射本地文案，不显示上游原始文本。确定性错误暂停，其他连续失败最多三轮；手动成功或重新启用可恢复。

## 边界核对

Manifest 只改变版本，没有权限扩大；凭据存储、DB schema、词典资源及用户数据不变。tf-markers-v2 通过既有身份机制隔离富文本缓存，纯文本身份保持。旧 0.8.48 包未覆盖。

真实页面 DOM 代码检查按原合同允许同层标记随语序重排，比较代码内容和次数；adapter 仍逐 marker 校验原文代码与父子结构。不能把固定 DOM 顺序假设当作代码损坏，也不能用任务 completed 代替可读截图。

## 限制

安全恢复可能降低跨格式片段的语境连贯性；校验针对可证实的协议/结构损坏，不承诺模型语义翻译永远准确。没有真实付费 Provider 或 ChatGPT 账号验收；Native 并发、断线和取消由合成 Host 回归覆盖。

期间两轮真实请求发生超时，控制请求及相同批次之后可成功，超时根因尚未确定；没有据此声称浏览器或服务端单独有故障。失败日志保留，最终真实结果见 validation-report.md。当前未发现需要继续修改最终候选源码的确定性问题。
