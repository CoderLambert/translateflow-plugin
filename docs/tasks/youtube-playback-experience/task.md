# YouTube 字幕播放体验优化

目标：让当前句先于未来字幕返回，并使倍速播放保有有界的提前翻译窗口。

范围：现有 Content subtitle source / TextTrack / YouTube adapter / pipeline，相关 Node 与浏览器回归及字幕规范；按用户追加要求将 pipeline.js 单文件行数上限放宽至900。保持 Provider、缓存身份、权限、MAIN 获取方式及取消后真实在途占用不变；不直接接入 FluentRead GPL 源码；不修改 Popup。

实现：当前活动字幕与未来字幕分批，未来批次至多两条；播放倍率贯穿 snapshot 与两种可提供完整时间线的 source，窗口按倍率调整但有硬上限。保持旧请求隔离、重复请求合并、重叠字幕顺序和缓存即时恢复。

验收：先记录旧实现的失败回归；当前字幕完成时不等待未来字幕响应；未来字幕晋级当前不重复请求；倍速窗口经过重复规范化不丢失，非法倍率有界；seek/换轨/切视频/取消不得导致旧结果回写或并发失控。运行受影响 Node 测试、静态检查、构建及 Chromium 字幕场景，实际 YouTube 可访问时补实播证据，否则如实记录阻塞。

交付：本地预览包、测试与自查记录。当前未授权新的提交、推送、合入或发布；版本保持基线 0.8.50。
