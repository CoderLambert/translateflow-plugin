# 富词典附件失败反馈与稳定降级布局

基于 `main@fef5eab3292f3e2d26c0ce85e073ac8fb1dcc598` 修复 Selection 中正文已命中、但 MDD/sidecar 附件不可用时的三个用户可见问题：Oxford CSS 未加载会让徽标占位纵向撑高；音频点击只显示含糊的“未导入”；entry 导航失败恢复当前正文后仍声称当前词条加载失败。

保持正文查询可用和本地资源安全边界。资源 resolver 必须保留 missing、stale、后台错误与前端校验失败的安全分类，并在当前 viewer 内聚合成一个可理解、可恢复的附件提示；提示可打开设置页重新选择完整资源。资源读取仍只走既有 `RICH_MDD_RESOURCE`，不发 Provider、不访问外网、不放宽 CSP/权限/容量限制。Oxford 小徽标缺失时使用紧凑的横向占位，普通插图仍明确显示缺失；不伪造徽标内容。

导航 miss 与 error/stale 都保留当前正文和历史游标，状态文案必须明确目标跳转失败而当前词条仍保留。关闭 viewer、selection generation 变化或旧资源请求返回后不得新增提示或覆盖当前状态。

验收覆盖：stylesheet missing/stale/corrupt/unavailable 分类与单一恢复提示；音频错误分类和可重试按钮；Oxford symbol 缺失的紧凑横向布局；普通图片降级不被隐藏；导航 miss/error/stale 回退文案；健康 CSS、图片、字体、音频和资源取消路径不回归。冻结候选后只执行一轮完整相关验收与 WXT/Chromium，真实私有 Oxford 只记录脱敏结果，不提交正文、文件名、路径或附件。

根因证据边界：完整私有测试安装中 commit 的 CSS/徽标/音频成功，仅证明健康对照；用户截图安装的底层资源响应尚不可访问，不能认定其文件缺失，也不能宣称恢复该原安装。已证实的链路缺陷是单个 CSS 图片 slot 非 missing 错误会丢弃整张有效样式表；修复为该 slot 降级 none 并提示，stale/closed 仍拒绝旧版本样式。音频错误只记录安全分类/错误码，不输出路径或正文。实际用户安装的修复结论须等待新包中的具体诊断。
