# 本地任务、验收与独立审核；GitHub 仅同步代码

## 目标、范围与所有权

主 Agent 单写本地任务/证据工具、规范、11 个 Actions 触发配置；复用现有 hooks，不修改运行时代码、依赖版本或全局配置。具名 dev_reviewer 独立只读审核准确候选。保留 #234 与路径修复的全部工作。

## 验收

完整 npm run validate；门槛正反例验证源码/合同变化、脏工作区、日志篡改、缺失/旧审核、依赖、产物与索引；Actions 仅手动、输入/jobs 不丢失；用 #234 本地卡证明缺失当前证据会拒绝同步。保护/自动审核设置只一次核对；不能调整的外部设置记明确限制。代码同步不读 Issue/评论/标签/CI，不绕过保护。

## 不做

不恢复产品开发、不重新配置 Agent、不新增平台/数据库、不调用模型统计或上传原始日志。
