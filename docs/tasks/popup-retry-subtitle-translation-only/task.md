# Popup 重试提示与仅译文字幕

## 目标与范围

基于已提交的统一版本0.8.53，按用户两张截图优化Popup页面信息读取失败的提示/重试区域；YouTube字幕新增“仅译文”模式，同时支持视频内选择、设置页默认值和偏好持久化。

- 重试使用既有视觉token和按钮，呈现清晰说明、键盘焦点、重试中禁用及成功/再次失败状态，保留受保护页面的真实限制。
- 仅译文隐藏扩展原文行并保持原生字幕层隐藏；译文未就绪/失败时不回退显示原文，保留状态提示。切换双语/仅译文复用已有结果及请求，不新增调度器。
- 在现有字幕模式校验链中增加 `translated` 值，旧偏好、默认双语、原文/关闭行为保持兼容；MAIN桥接仍只接收白名单模式，无新权限或存储schema。

## 验证与交付

按影响执行Popup/Options单元测试、字幕/设置/桥接Node回归、check、typecheck和真实编译包的针对性Chromium测试，保留明暗色重试截图及仅译文字幕截图。模拟播放器不冒充真实YouTube实播。主Agent自查后本地提交，沿用每次提交同步版本并构建约定；本次不推送或合入main。
