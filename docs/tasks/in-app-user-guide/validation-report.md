## 用户可见变化

- 设置侧栏增加独立「使用文档」；截图所示关于区域增加明显的文档入口，并将实现技术说明替换为产品介绍与版本信息。
- 使用文档按 12 个功能 Tab 切换：首次使用、AI 服务、网页翻译、AI 文本翻译、划词与 AI 解读、YouTube、词典、学习中心、站点与译法、快捷键、数据隐私、常见问题。每次仅展示当前主题的入口、三步操作、结果说明、恢复提示；额外细节折叠展示。提供上一页/下一页及直达相关设置的链接，切换设置时保留草稿。

- 设置页全部原生 React 选择框替换为统一展示：YouTube 字幕模式/大小、源语言、界面语言、AI 平台/协议/默认服务、翻译方式/在线服务、站点模式/外观、术语范围及开发版账号/模型。Popup 复用同一选择器。
- `StyledSelect` 保留原生 option 树与 React onChange 所有者，仅适配展示；配置值、默认选项、禁用和原有保存流程不变。共享菜单样式、键盘、ARIA、选中提示和按视口空间展开逻辑，长选项省略并可悬停查看完整名称。未扩大权限或新增依赖。
