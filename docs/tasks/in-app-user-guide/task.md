基线 b5b9a83（0.8.57）。用户要求在截图所示「开发者／关于」处增加完整使用文档，避免文字堆叠，功能按不同 Tab 切换并做好指引。

范围：关于页明显文档入口、设置侧栏独立使用文档栏目；同一设置页内按首次使用、AI 服务、网页翻译、AI 文本翻译、划词、YouTube、词典、学习中心、站点与译法、快捷键、隐私数据、问题排查切换。每页提供入口、三步操作、结果/恢复提示及直达设置；高级细节按需展开。覆盖中英、键盘 Tab/方向键/Home/End、窄屏与暗色。文档不触发 Provider，不读取页面或用户历史，设置加载失败时仍可查看。不复制新页面或增加权限。

追加范围：用户要求文档完成后统一优化截图所示选择框。将设置页全部 React 选择框（字幕模式/大小、语言、AI 服务平台与协议、查词方式、站点偏好等）统一为现有自定义菜单；共享 Popup 的键盘/ARIA、选中态与视口定位逻辑，保留原生 option/React change owner，不变更配置值和保存行为。

用户持续要求不追加自动测试；完成内容核对、自查、编译及构建内置审核后及时本地提交，交付人工试用，不推送或合入。
