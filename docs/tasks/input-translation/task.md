# 输入翻译小窗

基线：43405db082ad13eb234e64ef1bead9cdadce8c25（0.8.54）。用户授权实现前述产品规划，要求简单实用、重视 UI/交互，并沿用及时本地提交约定。

范围：Popup 独立入口、可配置快捷键、单实例扩展小窗；自动识别原文、选择目标语言与已有 AI 服务；翻译、复制、单条译文继续调整、重新翻译、停止、失败重试。复用后台 Provider、有效配置解析、严格输出校验及请求取消，不直接复用绑定网页的划词 Port。首版使用完整校验后的非流式结果。

会话：草稿和最近 20 条记录仅保存在 trusted chrome.storage.session；浏览器会话结束或用户清空后移除，不写入持久翻译缓存、Reading 或学习中心。关闭窗口断开 Port 并取消当前请求，重新打开将未结束记录标为中断。正常/隐身会话不混用；首版不在隐身环境启用。源文最多 6000 字符、调整要求最多 600 字符；超限明确反馈，不截断发送。

UI：复用暖米/鼠尾草绿 token，明暗、窄屏、键盘、中文输入法、焦点和减少动画；Enter 换行，Ctrl/Cmd+Enter 提交。配置选择只影响新请求，不改全局或站点设置。新内容不带其它对话历史，调整仅携带指定源文、译文和要求。

补充授权：用户要求引入其提供的插件图标，覆盖工具栏、扩展管理页、扩展页品牌/标签和网页品牌入口；按最新指令，图标整合后只构建并交付人工试用，不再追加自动测试。仅使用实际需要的五档 PNG，固定资源白名单，网页仅暴露 64px 图标。

实现：新增独立原生 TypeScript 扩展页（不扩 React 允许域）、受信消息与单请求 Port 适配器、session 状态和本地化；更新精确页面资产映射、Manifest command、Popup。无新权限或 Provider。

验收：后台单测涵盖来源限制、输入限制、请求快照、取消/断开与无持久化；UI 单测/真实编译包 E2E 覆盖受保护页入口、重复打开、翻译/调整隔离、复制、设置、重试/停止/重开/清空、窄屏暗色和截图。按改动运行 check/typecheck/Vitest、相关 Node、构建和 Chromium；真实网站/模型未执行时明确说明。本地提交，不推送或合入。
