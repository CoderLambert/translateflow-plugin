# 拖动翻译悬浮入口并记住本站位置

历史单项合同，现已并入 [content-runtime-closeout](../content-runtime-closeout/task.md) 作为同一候选的一部分；当前合入状态以该任务的 `state.json` 和 `acceptance.json` 为准。

用户选择“可拖动，并记住本站位置”。目标是让用户移开与网站悬浮按钮重叠的翻译入口。

- 范围：现有 Quick Control 的指针拖动、键盘移动、本站位置记忆、恢复默认位置、视口内布局及失败反馈。
- 位置只在用户完成移动或恢复默认时写入本地；保存本站 scope 与相对坐标，不保存页面正文、路径或查询参数。沿用现有 scheme + hostname 的本站规则。
- 复用 Shadow DOM、消息路由、现有翻译任务；不变更权限、Provider、缓存身份或现有设置格式。独立附加存储键有版本及站点数量上限。
- 历史单项开发曾与词典 AI、扩展上下文失效修复同在一个旧工作区；其分支/基线记录只说明当时实现环境，当前集成依赖由聚合任务管理。
- 验收：拖动不打开面板或请求 Provider；移动后网站按钮可点击；刷新恢复位置；本站隔离及重置；取消不保存；键盘、窄屏、暗色、减少动画、语言切换及原面板行为回归。
- 验证：定向 Node、check、typecheck、默认 WXT 构建、消费实际默认安装包的定向 Chromium E2E 与截图。
- 原单项授权为本地实现及验证，当时不包含提交、推送、合并或发布；当前授权与验收由聚合任务管理。
