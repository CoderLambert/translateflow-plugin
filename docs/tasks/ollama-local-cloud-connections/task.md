# Ollama、本地部署与云端模型连接

用户要求：字幕修复合入后，放宽 AI 接入，支持 Ollama、本地部署和云端模型。

在现有连接管理中增加 Ollama 本地、Ollama Cloud、LM Studio 预设。保留通用自托管、自定义云平台和现有四协议。模型 ID 自由填写，不限定模型白名单、不自动换服务。只对这些新预设规范化常见服务根地址；自定义地址和旧连接保持原语义。

本地预设默认允许无 Key 和 HTTP；云端默认要求 Key。设置页说明模型名称、地址及已登录本地 Ollama 转发云模型的区别。HTTP、凭据、权限、Effective Config、缓存身份继续走现有实现，不增加协议、消息、权限或数据库迁移。

验收：新增连接的规范化与身份回归、设置页预设交互、现有 Provider 协议测试、类型检查、构建、MV3 保存/测试/翻译/刷新恢复。修正已有 smoke fixture 未指定 AI 路由造成的 MT_CONSENT 失败，并复验。真实模型单独记录；不下载模型，不调用已有云端账户，不将 mock 通过等同于模型兼容。

本轮不自动提交、推送或合并新功能；用户此前提交授权对应已交付的 YouTube 修复。
