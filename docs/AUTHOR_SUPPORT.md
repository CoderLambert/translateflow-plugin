# TranslateFlow 爱发电支持入口

用途：提供完全自愿的作者支持。支持与扩展功能、AI 服务费用分开，不接入支付 API，不索取订单、付款身份或支持者名单，不按付款状态解锁功能。本站点已核对为 https://afdian.com/，首页说明其为连接创作者与粉丝的会员制平台；具体开户、实名、提现、手续费及支付周期以登录后的当前平台说明为准。

## 需要维护者本人完成

1. 在爱发电注册/登录自己的账号，按平台流程开通创作者主页。
2. 仅在爱发电官方页面填写本人实名、收款或提现信息、验证码及必要协议；不要把这些信息发给代理或放进项目。
3. 设置公开主页信息，下面文案可以直接复制。主页名称、简介可按个人偏好调整。
4. 如果平台要求设置方案，创建一个简单的自愿支持方案。可以参考5元或10元，不将金额与功能或翻译额度绑定。支付是一笔还是按月，需依据实际选项明确说明，不能把订阅写成一次性付款。
5. 以未登录访问者视角检查主页是否可见、收款人和支付周期是否正确。复制平台实际提供的公开创作者主页链接。

只需把公开主页链接提供给项目，就能完成 README 和关于页接入；不需要 API Token、User ID、订单查询、支付回调、身份证或银行卡信息。维护者已提供并确认公开主页：https://afdian.com/a/transflow 。保持原样使用 transflow，不擅自改成 translateflow。插件展示主页分享二维码，不是直接付款码；二维码由本机 qrencode 从同一 URL 生成。
