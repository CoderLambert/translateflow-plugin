# 本地词典下载、授权与导入

TranslateFlow 提供本地词典阅读和查询能力，基础扩展不附带词典正文。**支持 MDX/MDD 格式，不等于拥有相应词典的复制、改编或分发授权。** 也不要将词典查询宣传为任意句段的离线翻译；它依赖词典中已有的词条。

## 下载后怎么导入

1. 先解压 ZIP、tar.xz 等下载包；不要把压缩包直接当作 MDX/StarDict 文件选择。
2. StarDict：一起选择同名 `.ifo`、`.idx` 和 `.dict` 或 `.dict.dz`。如果这套词典还带 `.syn`，也一并选择；不要把不同词典的文件混在一起。
3. MDX：选择 `.mdx`，如有配套 `.mdd`、编号 MDD、CSS、图片和音频，按提示一并导入，或选择对应文件夹。保留匹配文件名。
4. 等待检查和保存成功，在词典库启用该词典。随后在「通用」把单词查询方式设为词典，保存，再到网页选词。
5. 缺图、缺音频或不支持某些交互时，先核对伴随资源与提示。不要为了恢复原词典的 JavaScript 功能而开放脚本或远程资源。

词典导入与查询在本机完成；TranslateFlow 不执行词典脚本，也不自动请求词典内的远程图片、在线 TTS 或代理服务。仅点击 AI 解读等操作时，才按该操作与配置的服务规则处理所需文字。

## 为什么没有推荐用户提供的论坛帖子

本次核对的[FreeMdict 帖子](https://forum.freemdict.com/t/topic/25795)介绍牛津、韦氏、剑桥等词典的改版。帖子自述包含官网抓取、官方 App 提取或其他版本内容，并出现“尊重版权，私下传播”的描述；尚未找到权利人允许这些完整词典公开分发的依据。这是**未确认授权的风险判断**，不是对整个论坛或每个文件作法律定性。

因此不把该帖或其中网盘地址列为本产品的“正版免费词典下载”、精选安装源或官方推荐，也不复制网盘提取码、不镜像或打包其中词典。用户依法取得、获准使用的本地文件仍可按既有导入路径使用。

技术上，帖子也说明主要在欧路词典测试，包含依赖外部 JavaScript、在线 TTS 与代理的功能；这不等于在 TranslateFlow 完整兼容。本扩展继续保持脚本不执行和远程资源不自动加载的边界。

[《中华人民共和国著作权法》（2020年修正，WIPO Lex 收录）](https://www.wipo.int/wipolex/en/legislation/details/21065)第十条涉及复制权、信息网络传播权等；第二十四条的个人学习和适当引用有适用条件，不能据此直接推导出整部商业词典可以公开上传、宣传下载或重新打包。单独增加“仅供学习”“版权归原作者”等文字不能替代应当取得的授权。
