TranslateFlow

DeepSeek Key 与普通设置保存在 Chrome 扩展本地存储；网页翻译结果保存在扩展自身的 IndexedDB 中。

模型或 Prompt 修改后会形成新的缓存版本，旧缓存不会误复用。

默认 200 MB。每次产生新翻译后按最近最少使用（LRU）策略清理超额缓存。

翻译缓存

缓存按“规范化 URL + 模型/Prompt/目标语言 + 原文 SHA-256”区分。移除 utm_*、fbclid、gclid 等常见跟踪参数，但保留业务查询参数。

使用方法

  1. 填写 API Key 并保存。
  2. 打开英文网页，点击扩展。
  3. “翻译 / 更新”会先命中缓存，只把缺失或变化的段落发送到 DeepSeek。
  4. 再次进入网页时可点击“仅恢复本页缓存”，全程不调用 API。
  5. 需要自动化时，在插件弹窗开启“此站自动增量翻译”；以后进入该站会自动恢复缓存并只补译近视口的新内容。
