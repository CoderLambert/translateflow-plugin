TRANSLATEFLOW SETTINGS

设置

管理翻译行为、阅读外观、Provider、站点规则与本地缓存。高级配置保持可见，但不会抢占日常设置。

通用

设置默认翻译行为。Provider 凭据和缓存维护已移到高级区域。

站点级设置可覆盖这些默认值；翻译配置变化会形成新的缓存版本。

外观

Standard / Compact / Reading / Minimal 只改变译文排版与视觉层级，不改变翻译缓存 identity。

YouTube

TranslateFlow 双语字幕在 YouTube 播放器中使用这些默认显示设置；播放器内仍可临时调整 Preset。

字幕翻译继续复用当前站点 Profile / Preset / Glossary / Provider 有效配置。

键盘快捷键

TranslateFlow 提供三个浏览器内快捷操作。Chrome 最终绑定以 chrome://extensions/shortcuts 为准，你可以在那里查看、修改或清除任意绑定。

翻译 / 更新当前页Ctrl+Shift+YmacOS: Control+Shift+Y
显示 / 隐藏译文Ctrl+Shift+KmacOS: Control+Shift+K
切换 Quick ControlCtrl+Shift+.macOS: Control+Shift+.

快捷键只在 Chrome 获得焦点时工作。浏览器或操作系统保留的快捷键优先级更高；如某个组合在你的系统上不可用，请在 Chrome 的扩展快捷键页面重新绑定。Chrome 内部页等受保护页面不会注入 TranslateFlow。

Provider · OpenAI-compatible

填写到 API 根路径即可；插件会自动追加 /chat/completions。也可直接填写完整 /chat/completions 地址。

首次使用某个 API Origin 时，Chrome 会单独询问访问权限。

站点

用于 GitHub、文档站、新闻站等不同场景。未填写的字段继承默认配置。

Preset 只贡献翻译风格；如果本站填写了自定义 Prompt，则自定义 Prompt 优先。

留空继承默认阅读外观。外观覆盖只改变本站译文显示，不影响 Provider 请求或缓存 identity。
