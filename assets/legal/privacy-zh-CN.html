TranslateFlow 隐私政策

适用范围：TranslateFlow Chrome 扩展公开版。本政策随扩展提供；开发者为 GitHub 项目 CoderLambert/translateflow-plugin 的维护者。

我们如何处理数据

TranslateFlow 用于翻译和理解网页、字幕及用户输入的文字，并提供本地词典与学习记录。扩展没有由维护者运营的翻译中转服务器，不内置广告、使用分析或向维护者自动发送诊断报告。它仍会处理网页内容、网址、用户输入及服务凭据，不能据此称为“不处理任何数据”。

数据 用途与保存位置 何时发送到外部
页面、选区、字幕和相关上下文 提取待翻译内容；已成功的页面/字幕译文可保存在本机缓存 用户触发在线翻译/AI 解读，或启用相应站点自动翻译后，发送到对应翻译服务。AI 解读可能包含所选内容的上下文与当前操作相关的历史
AI 文本翻译中的原文、要求、译文 提供翻译、复制和单条调整；草稿及最近 20 条结果保存在浏览器会话存储 仅主动提交时发送给选定 AI 服务；调整会发送目标原文、上一份译文和要求，新文字不携带无关对话
API Key、服务地址和设置 保存在当前浏览器配置中的扩展本地存储 密钥用于向所配置服务认证；不会作为页面内容或反馈报告主动发送给项目维护者
网址、页面标题、选段、收藏及已保存的 AI 内容 用于缓存身份、站点偏好、阅读回访和学习；阅读记录遵循独立的启用/同意与站点排除设置 阅读记录的保存和本地查看本身不调用翻译服务；用户在记录上明确触发 AI 功能时，会发送该操作需要的内容
导入词典和伴随资源 保存在本机，供本地查询和展示 本地查词不会上传词典文件。用户另行点击 AI 操作时会发送该操作所需文本；不上传整个词典

外部服务与联网

  • 自选 AI 服务：由用户设置地址和模型，例如 OpenAI、DeepSeek、其他兼容服务或自托管模型。请求直接发往所配置地址；该服务可能有自己的收费、日志、保留、训练使用和跨境处理规则，请阅读服务方政策。TranslateFlow 无法删除对方已收到的数据。HTTP 自托管连接须明确启用，内容可能未加密；本地地址也不保证服务不会转发云端。
  • 免费在线翻译：当前提供 Microsoft、Bilibili、Google、Volcengine、Youdao 和 Tencent Transmart 网页服务入口。自动模式的候选为 Microsoft、Bilibili、Google、Youdao；失败切换可能让同一段文字被多个候选服务接收。固定模式使用所选服务。界面要求同意发送文本；撤回并保存后相应范围停止新的上传。网页服务可能限流或失效，失败不会自动改用付费 AI。
  • Chrome 本地翻译：可用时由浏览器在设备上执行，可能先由 Chrome 下载模型；下载和浏览器自身处理受 Chrome 的政策约束。
  • 词典下载与外部链接：主动下载词典会连接界面说明的数据来源，下载服务可能获得 IP 地址和通常的请求信息。点击支持页、词典中的允许链接或本政策外部链接会打开相应网站，受其政策约束。仅查看本地政策、许可和本地词典不会触发这些下载。
  • 外部服务通常可以看到连接 IP 和请求元数据。页面内容本身也可能含个人、财务、健康或通信信息；请勿将不愿分享的内容提交给在线服务。插件不提供自动脱敏保证。

权限和用户控制

公开版使用 storage 保存设置及会话，使用 activeTab、scripting 提供当前网页操作。普通 HTTP/HTTPS 网站访问权限用于自动启动划词、悬浮控件和授权后的翻译功能；访问权限本身不等于把所有浏览内容上传。declarativeNetRequestWithHostAccess 仅用于调整本扩展发往 Bilibili 指定翻译端点的请求头。

公开版不申请 Native Messaging 权限，也不提供实验性的 ChatGPT 订阅本地组件连接。开发版为独立实验范围，需用户明确启用；不得将开发版能力作为公开版承诺。

你可以在扩展设置中更换翻译方式、关闭自动翻译、撤回免费在线同意、暂停阅读记录、排除站点，并在 Chrome 扩展设置中限制网站访问。站点单独设置与全局设置可能不同，应分别核对。自动恢复缓存只恢复命中，不因缺失而隐式调用在线服务。

保留、导出和删除

  • 设置和 API Key 保留至修改、删除相应连接或移除扩展。密钥保存在扩展本地存储中，不是额外加密的密码保险库；请保护浏览器配置和设备账号。
  • 翻译缓存按容量、有效性和清理规则管理；可在设置 → 缓存中清理。清缓存不会同时删除词典、收藏或阅读记录。
  • 词典可在词典库中卸载；收藏与阅读数据在学习中心各自管理，可按现有入口删除或导出。暂停记录不会删除已有记录。
  • 文本翻译窗口的会话数据在浏览器会话结束或点击“新对话”并确认后清除；Chrome 重新加载/禁用扩展也可能使会话存储清空。关闭小窗本身不等于清空会话。最新 20 条之外的条目会被淘汰。
  • 扩展不提供维护者服务器上的账号存储或云同步。导出文件和原始词典文件由用户自行保管；移除扩展不会删除用户另外保存的文件，也不会删除外部翻译服务保留的数据。

Limited Use 承诺

TranslateFlow 对用户数据的使用和转移遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。数据仅用于提供或改进明确面向用户的翻译与阅读学习功能；不出售数据，不将数据用于个性化广告、数据经纪或与这些功能无关的用途。维护者不会通过插件自动收集或人工阅读用户的翻译内容。用户主动提交支持信息时，维护者仅为处理请求而使用所提交内容。

联系、反馈和政策更新

维护项目：CoderLambert/translateflow-plugin。一般反馈可使用 GitHub Issues。Issues 是公开区域，请勿提交 API Key、私人页面、聊天内容、词典原文件或含隐私的截图；安全问题先只报告不含利用细节和秘密的联系请求。

政策会随功能与数据处理方式变化更新。涉及新的数据用途或上传行为时，会更新说明，并在需要时通过产品界面重新取得同意。商店填写的公开政策 URL 应指向与所发布版本相符的政策。
